- **Summary**:
  - (HTML5, CSS3, ES6+ JavaScript)
  - Built-in Dark and Light mode switcher with `localStorage` persistence
  - Interactive project showcase with native HTML5 `<dialog>` modals
  - Dynamic scroll-spy navigation using the `IntersectionObserver` API
